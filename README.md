# سینمود | فیلم‌یاب تعاملی (وب ۳)

یک تجربه‌ی سینمایی راست‌چین برای پیدا کردن فیلم از روی حال‌وهوا، ژانر و علاقه‌مندی‌ها. این پروژه برای بخش «وب ۳ ـ فیلم‌یاب تعاملی» چالش سینمود ساخته شده و از فایل نمونه‌ی `movies_sample.json` استفاده می‌کند.

## امکانات

### موارد اصلی چالش
- خواندن `movies_sample.json` با `fetch` و `async/await`
- ساخت کارت‌های فیلم با JavaScript و DOM
- جست‌وجو بر اساس عنوان فارسی یا انگلیسی
- فیلتر ژانر و پنج حال استاندارد: `happy`، `sad`، `angry`، `surprise` و `neutral`
- افزودن و حذف فیلم از نشان‌شده‌ها با ذخیره‌سازی `localStorage`

### امکانات اضافه
- مرتب‌سازی بر اساس امتیاز و سال ساخت
- پنجره‌ی جزئیات هر فیلم
- فیلترهای قابل حذف و حالت بدون نتیجه
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- پوسترهای گرافیکی ساخته‌شده با CSS برای فیلم‌هایی که لینک پوستر ندارند
- پشتیبانی از کلید میانبر `Ctrl/⌘ + K` برای رفتن به جست‌وجو

## اجرای پروژه

۱. پوشه‌ی پروژه را در VS Code باز کن.
۲. افزونه‌ی **Live Server** را نصب کن، اگر از قبل نصب نیست.
۳. روی `index.html` راست‌کلیک کن و `Open with Live Server` را انتخاب کن.
۴. مطمئن شو `movies_sample.json` کنار `index.html` قرار دارد.

> فایل را با دوبار کلیک و آدرس `file://` اجرا نکن؛ در این حالت ممکن است `fetch` به فایل JSON دسترسی نداشته باشد.

## منطق برنامه، به زبان ساده

1. `loadMovies()` فایل JSON را با `fetch` می‌خواند و به داده‌ی JavaScript تبدیل می‌کند.
2. `populateGenres()` گزینه‌های فیلتر را از ژانرهای واقعی فایل می‌سازد.
3. `getFilteredMovies()` جست‌وجو، ژانر، حال، نشان‌شده‌ها و مرتب‌سازی را اعمال می‌کند.
4. `renderMovies()` کارت‌ها را با DOM به‌روزرسانی می‌کند.
5. `toggleFavorite()` شناسه‌ی فیلم را در `localStorage` ذخیره یا حذف می‌کند.
6. `openMovie()` جزئیات فیلم انتخاب‌شده را در پنجره‌ی نمایش جزئیات نشان می‌دهد.

## نکته درباره‌ی داده‌ها

اطلاعات نام، سال، ژانر، حال‌ها و امتیاز از فایل نمونه خوانده می‌شوند. چون فیلد `poster` در نمونه‌ها خالی است، کارت‌ها از تصویرسازی گرافیکی CSS استفاده می‌کنند و پوستر واقعی جعل نمی‌شود. دسته‌بندی حال‌ها همان داده‌ی قراردادی پروژه است و تشخیص واقعی احساس چهره در محدوده‌ی این بخش نیست.
